# 手帐风个人网页生成

你的任务：把用户的任意主题，做成一页"手帐本内页"气质的单文件 HTML 网页。
风格骨架固定（见下），血肉（文案、贴纸意象、涂鸦、配色中的强调色选择）随主题生长。

## 第一步：读取风格系统

开始前先读 [references/style-guide.md](references/style-guide.md)——里面有完整的设计 token
（色板、字号、旋转角度、贴纸做法）和检查清单。本文件只讲流程和判断。

## 第二步：从主题提炼"手帐母题"

先想清楚这个主题在手帐里会长成什么样，再动手写代码：

- **贴纸意象**：主题里有什么能变成"贴纸"的具体物？读书→书签、咖啡渍、眼镜；健身→哑铃、水壶、秒表；宠物→爪印、毛线球、罐头。每个分区配 2–3 个，宁少勿多。
- **便利贴内容**：哪些信息适合写成"便利贴/便签"体（短句、口语、带一点自嘲）？哪些适合写成"内页正文"？
- **强调色**：纸底色和墨色永远不变；从主题里挑 1–2 个低饱和强调色（色板见 style-guide），比如海洋主题取雾蓝、植物主题取鼠尾草绿。
- **涂鸦与符号**：手绘箭头、星星、波浪线用来连接和圈注内容，别当装饰堆砌。

## 第三步：生成页面

1. 以 [assets/template.html](assets/template.html) 为起点（它已经实现了全部 CSS token 和贴纸/胶带/活页环的画法），替换内容与文案。
2. 单文件交付：HTML + 内联 CSS/JS，不依赖本地图片。贴纸和插画一律用 emoji + CSS 白边贴纸效果、或内联 SVG 手绘涂鸦实现；外部字体可引用 CDN，但必须有系统楷体/手写体兜底。
3. 页面结构遵循"一本翻开的活页本"：页首是手写大字 + 一两张主贴纸；正文分成 3–6 个"内页"分区；页脚像书的封底（一句话 + 小涂鸦）。

## 第四步：自检（对着 style-guide 末尾的清单）

生成完必查这几条，不合格就改：

- 强调色 ≤ 2 个新增色，底色/墨色没被动过。
- 卡片旋转角在 -2.5° ~ 2.5°，且相邻元素角度不同；没有任何元素是横平竖直地"排排坐"的。
- 有足够留白：分区间距 ≥ 56px，贴纸之间互不贴脸。
- 动效只有"轻微"级别：hover 微浮起/微摆动、进场淡入，无大面积动画。
- **原创性**：文案、贴纸组合、涂鸦都是为当前主题现做的；如果成品和某个现成站点结构雷同，重新组织。
- 空目录、死链接、缺兜底字体的地方清零。

## 边界

- 用户明确要别的风格（极简、暗黑、瑞士风）时，本技能让路，不要硬套。
- 用户要"多页站点"时，每页仍用同一套 token，仅内容不同；默认先交付单文件主页。
