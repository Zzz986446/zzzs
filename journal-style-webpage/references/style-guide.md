# 手帐风视觉系统（Style Guide）

这套系统的气质一句话：**一本被认真打扮过的活页手帐本**——纸是底，墨是字，贴纸和胶带是情绪，动效只是纸页被风碰了一下。

来源信号（提炼自小红书 @Sira 手帐个人主页帖及其评论）：活页本金属环、可爱贴纸、"稍微一点点动态"、留白大方、手帐拼贴排版。提取的是**规律**，不是素材——生成时必须重新组合。

---

## 1. 配色（固定骨架 + 主题强调色）

| 角色 | 色值 | 说明 |
|---|---|---|
| 纸底色 | `#FAF6EC` | 大面积，永远用它。可加极淡噪点/圆点格纹理（透明度 < 6%） |
| 深纸色（卡片/内页） | `#FFFDF6` | 白卡、便利贴的底，比纸底亮半度 |
| 墨色（正文） | `#4A3B32` | 暖棕黑，禁止纯黑 `#000` |
| 浅墨（次要文字） | `#8A7A6D` | 注释、日期、标签 |
| 线条色 | `#D9CDBB` | 虚线、边框、分隔 |

**主题强调色**：从下面挑 1–2 个（按主题气质），只能挑 1–2 个：

- 番茄红 `#E2795F`（活力、美食、生活记录）
- 芥末黄 `#EFBE4F`（高亮笔效果、温暖）
- 鼠尾草绿 `#9DB89A`（植物、健康、平静）
- 雾蓝 `#9FBDD3`（海洋、学习、理性）
- 藕粉 `#E8B4B8`（可爱、宠物、柔和）

规律：**底色占 ≥ 70%，墨色 ~20%，强调色 ≤ 10%**。强调色用在荧光笔高亮、胶带、贴纸描边上，不做大面积色块。

## 2. 布局：一本翻开的活页本

- 单栏主轴，`max-width: 760px` 居中，两侧大量留白。
- **活页环**：页面顶端居中画一排 5–7 个金属环（CSS 圆环，灰银色渐变），是整页"这是本子"的锚点。
- 每个**分区 = 一张内页卡片**：白底、`border-radius: 6px`、极淡投影 `0 2px 8px rgba(74,59,50,0.08)`、微旋转。
- **旋转是灵魂**：每张卡片/贴纸/胶带都有 `-2.5° ~ 2.5°` 的随机小角度，相邻元素角度必须不同。绝不允许一列卡片 0° 整齐排列。
- 分区之间用虚线骑缝线、手绘箭头或一小段胶带衔接，不用通栏分割线。
- 照片/插图一律装在**拍立得白框**里（白边下宽）+ 底部一小条和纸胶带固定。

## 3. 字体气质

- **标题**：手写/圆润体。中文可用站酷快乐体（`ZCOOL KuaiLe`，Google Fonts）或霞鹜文楷（CDN：`lxgw-wenkai-webfont`）；英文用 `Patrick Hand` / `Caveat`。
- **正文**：霞鹜文楷 / 系统楷体（`Kaiti, STKaiti, serif` 兜底）。禁止黑体、微软雅黑做标题。
- 标题配**波浪手绘下划线**（内联 SVG）或**荧光笔高亮**（芥末黄半透明背景 `linear-gradient` 斜切）。
- 字号节奏：主标题 40–56px，分区标题 24–30px，正文 16–17px / 1.9 行高（手帐字要松）。
- 数字和日期可用 `Courier Prime` 打字机体，制造"手写批注 + 打字记录"的层次。

## 4. 插画质感：贴纸、胶带、涂鸦

- **贴纸 = emoji 或 SVG + 白色介刀边**：`border: 4px solid #fff` + `border-radius` + 投影 `0 3px 6px rgba(0,0,0,0.15)` + 微旋转。尺寸 40–80px，每个分区 2–3 枚，贴在卡片边缘（可一半探出卡外）。
- **和纸胶带**：`width: 90–120px; height: 26px;`，半透明强调色 + 斜纹（`repeating-linear-gradient`），两端用 `clip-path` 做锯齿撕口，压在照片/卡片一角。
- **便利贴**：3×3 或 4×4 的方块，浅色底 + 顶部一条胶带 + 手写体短句。
- **手绘涂鸦**：星星、箭头、圆圈批注、波浪线——全部内联 SVG，`stroke: 墨色`，`stroke-width: 2`，`stroke-linecap: round`，路径故意不闭合、有点抖。涂鸦用来**圈注和引导视线**，不是填空的装饰。
- 允许一个"手作痕迹"：咖啡渍、铅笔蹭痕、撕纸边（`clip-path` 多边形），全页最多 1–2 处。

## 5. 留白与排版

- 分区垂直间距 ≥ 56px；卡片内 padding ≥ 24px；贴纸之间至少隔 16px。
- 正文写成**短段**：2–4 行一段，段落之间空行。手帐是短句，不是论文。
- 列表符号换成手绘感：`•` 换 `✦` / `◦` / 小箭头 SVG。
- 日期、标签用浅墨小字 + 打字机体，像手帐角落的批注。
- 每页允许一处"大留白"：一个只放一句话和小涂鸦的区域，是呼吸口。

## 6. 动效：纸页被风碰了一下

- 进场：`opacity 0→1` + `translateY 8px→0` + 旋转归位，0.4–0.6s ease-out，逐个延迟 80ms。
- Hover：贴纸/卡片 `translateY(-3px)` 轻浮起 + 投影加深；贴纸可加 `rotate ±1.5°` 摆动一次。
- 禁止：视差滚动、无限循环动画、大面积位移、弹跳缓动。

## 7. 原创性红线（"像，但不抄"）

保留的是这套**规律**：纸底色、暖墨字、微旋转拼贴、胶带固定、活页环锚点、大留白、轻微动效。

每次生成必须重新决定：贴纸是哪几枚、文案怎么写、强调色选哪个、涂鸦画什么、分区怎么切。
如果成品的贴纸组合、分区结构、文案和任何现成站点（包括 Sira 原帖）雷同，推倒重组——**母题来自用户的主题，不来自模板库**。

## 8. 交付自检清单

- [ ] 底色 `#FAF6EC`、墨色 `#4A3B32` 未被改动；新增强调色 ≤ 2
- [ ] 页顶有活页环，所有卡片/贴纸都有 ≠0° 且互不相同的小旋转
- [ ] 标题是手写体且有荧光笔高亮或波浪线；正文行高 ≥ 1.8
- [ ] 分区间距 ≥ 56px；存在至少一处纯留白呼吸区
- [ ] 动效全部 ≤ "轻微"级别，无循环动画
- [ ] 单文件、无本地图片依赖、字体有系统兜底
- [ ] 所有文案、贴纸、涂鸦均为当前主题原创
